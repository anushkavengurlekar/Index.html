STAGE 1: DATA INGESTION

Dataset Aggregation from PhishTank & Benign Sources

The project uses a balanced collection of 88,647 URLs. Phishing samples were obtained from the verified PhishTank database, while safe URLs were sampled from legitimate university archives and the Alexa/Tranco top domains list to train classifiers without bias.

Key Tools: Python 3, Pandas, Scikit-learn, urllib.parse

Academic Synopsis

Project Abstract: Fake & Phishing URL Detection

Introduction: Phishing attacks commonly use spoofed and deceptive URLs to trick users into divulging credentials and sensitive information. Traditional database blacklists cannot detect newly crafted zero-hour links before they are reported.

Objective: To develop an automated classification system that analyzes structural and lexical patterns in a candidate URL to determine whether it is legitimate or malicious before navigation occurs.

Methodology: A dataset of 88,647 URLs was processed to extract 18 lexical properties, including character length, Shannon entropy, presence of IPv4 addresses, suspicious top-level domains, and security-sensitive tokens. Supervised machine learning algorithms (Logistic Regression, Decision Trees, Random Forest, and XGBoost) were evaluated.

Conclusion: The Random Forest classifier demonstrated the highest performance with 97.85% accuracy and an F1-score of 97.87%, making it suitable for lightweight client-side verification.
